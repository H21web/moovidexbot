Keyless subtitle proxy (v10.12.3):
- New env var SUBS_PROXY_URL — your own CORS proxy. Recommended: the
  free Cloudflare Worker in subs-proxy-worker.js (paste into
  dash.cloudflare.com -> Workers & Pages -> Create Worker -> Deploy).
  Then set SUBS_PROXY_URL=https://<name>.<you>.workers.dev and redeploy.
- Subtitle fetch order (no API key needed):
  direct -> browser headers -> YOUR worker -> public proxies
  -> official API (only if OPENSUBTITLES_API_KEY set).
